# lab — 情報デザイン学部 先生たちのページ

開志創造大学 情報デザイン学部の先生が、**自分で書いて更新する** 教員ページです。
「この先生と何を学び、何を作れるか」が伝わるように、授業・研究・プロジェクト・学生の作品・オフィスアワー・学生へのメッセージを載せます。

- サイト: https://kaishi-lab.pages.dev （のちに https://lab.kaishi.ac.jp ）
- 公式の教員紹介: https://kaishi.ac.jp/info-d/teacher/ （氏名・経歴・写真はここから自動で取り込みます）

### 編集のしかた（3 通り。どれでも OK）

| やり方 | こんな先生に | 手順 |
|---|---|---|
| **A. フォームで頼む** | GitHub の画面に慣れていない | [「自分のページに情報を追加・更新したい」](https://github.com/Kaishi-info/lab/issues/new?template=profile.yml) に書いて送る。担当者（または AI）が反映します |
| **B. ブラウザで直接編集** | 自分で書きたい | 上の表の「自分のファイル」を押す → 書きたい項目の先頭の `# ` を消して書く → 「Commit changes」→「Propose changes」→「Create pull request」 |
| **C. AI に頼む** | Claude Code などを使っている | 「AGENTS.md を読んでから、私（白井）のページにオフィスアワーを追加して」のように頼む。Git の操作も AI が行います |

B・C は PR（変更を見てもらう申請）になります。自動チェックが通ると **プレビュー URL** が PR にコメントされるので、公開前に見た目を確認できます。マージ（取り込み）されると本番に反映されます。

### ページのどこが、YAML のどの項目か

ファイルには使い方のコメント付きで全項目が並んでいます。**書いた項目だけがページに出ます**（空欄は表示されません）。

| ページの欄 | YAML の項目 | 書くこと |
|---|---|---|
| 名前の上のひとこと | `catchcopy` | 「○○を使って、○○をできるようにする」（60字まで） |
| 分野のタグ | `clusters` | 学部の領域（`generative-ai` `ui-ux` `hci` など。一覧は [src/lib/taxonomy.ts](src/lib/taxonomy.ts)） |
| この先生から学べること | `learn` | 3〜5 項目 |
| 担当科目 | `courses` | 科目名・概要は自動で出ます。**作るもの・到達目標・課題・授業動画やスライド** を書き足せます（`name` を科目名と同じに） |
| 研究・制作・社会実装 | `projects` | プロジェクト名、種類、年、連携先、URL |
| 学生の作品・成果 | `works` | 作品名、授業、URL（**学生の氏名は本人の同意がある場合だけ**） |
| 研究 | `researchThemes` / `researchmap` | 研究テーマ／researchmap の ID を書くと論文・発表が自動で並びます |
| こんな人と一緒に学びたい | `message` / `lookingFor` / `consult` / `careers` | メッセージ、来てほしい人、相談に乗れること、つながる進路 |
| オフィスアワー | `officeHours` | 書くと科目一覧の時間より優先されます。時刻は `"18:00"` のように引用符で囲む |
| 参加・相談の入口 | `join` | ゼミ・プロジェクト・高大連携・共同研究などの案内 |
| リンクのボタン | `x` `bluesky` `instagram` `note` `youtube` `github` `linkedin` `website` `portfolio` `lab` `links` | SNS は @ なしの ID、ほかは URL |
| 最近の活動 | `topics` / `feeds` | 自分で書くトピック／ブログ・note・YouTube の RSS を書くと新着が自動で並びます |
| 自己紹介 | `bio` | 自由に（Markdown が使えます） |
| 立場別のひとこと | `audiences` | 高校生・社会人・企業などに向けたひとこと |

書き間違いがあると PR の自動チェックで教えてくれます。全項目の正確な定義は [src/content.config.ts](src/content.config.ts) にあります。
全員の記入状況は [整備状況のページ](https://kaishi-lab.pages.dev/status/) で見られます。

### 自分のファイルでは直せないところ

| 情報 | 元のデータ | 直したいとき |
|---|---|---|
| 氏名・職位・経歴・公式の写真・「高校生／社会人のみなさんへ」 | 大学公式サイト（毎日自動で取り込み） | 公式サイトを直してもらう。表示だけ変えたいなら自分の YAML の `photo` / `specialty` で上書きできます |
| 担当科目の一覧・科目概要・科目一覧のオフィスアワー | 教務の科目一覧（CSV） | 教務に連絡。オフィスアワーは自分の YAML の `officeHours` で上書きできます |
| researchmap の論文・発表 | researchmap（毎日自動で取り込み） | researchmap 側で直す |

### 載せてはいけないもの

公開リポジトリなので、書いた内容は誰でも読めます。

- 学生の個人情報（作品に名前を出すのは本人の同意がある場合だけ）
- 評価シートの点数など人事・評価の情報、未公開のシラバス原文
- 個人の電話番号・メールアドレス（載せたいと決めたもの以外）、パスワードなどの秘密の値
- 権利のはっきりしない画像

## 運営・開発者向け

### 自動で取り込まれる情報

| 情報 | 置き場所 | 更新 |
|---|---|---|
| 公式サイトの氏名・職位・経歴・メッセージ・写真 | `data/official/<ID>.yaml` | 毎日 03:00 にチェックし、変更があれば PR を作成 |
| 科目一覧（科目概要・担当・オフィスアワー） | `data/curriculum.yaml` | CSV が更新されたら `pnpm import-curriculum` |
| researchmap の業績・RSS の新着 | `data/feeds/<ID>.yaml` | 毎日取得して自動公開 |

`data/` 以下は機械が書くファイルです。手で編集しないでください。X は API が有料のため、投稿の自動取り込みはしていません（リンクのみ）。

### 評価シートから「年度の取り組み」（`highlights`）の下書きを作る

教育職員評価基準シート（xlsx）の **本人コメント（目標・実績）と本人総括だけ** を読みます。点数・教員平均・評価者コメントは読みません。

```bash
pnpm import-eval ~/Downloads/教育職員評価基準シート....xlsx shirai-akihiko
```

下書きは `.private/<ID>-eval.yaml`（Git に入らない場所）に出ます。評価シート本体はコミットしないでください（`.gitignore` と CI で防いでいます）。

### 先生に聞いてみる（質問フォーム・準備中）

`/ask/` は 1 問ずつ答えるチャット型の質問フォームです。通知（Resend / Slack / Discord / Teams）の準備ができるまで入口は非表示です（[#2](https://github.com/Kaishi-info/lab/issues/2)）。
送信は `functions/api/ask.ts`（Pages Functions）。メールアドレスや Webhook URL は Cloudflare Pages の環境変数にだけ置きます（`pnpm secrets`）。

### コマンド

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # dist/ に静的サイトを出力（YAML の検証も兼ねる）
pnpm check      # 型チェック
pnpm scrape     # 公式サイトを取り込む（新しい先生の雛形と、この README の先生一覧も更新）
pnpm feeds      # researchmap・RSS を取り込む（pnpm feeds <ID> で 1 人だけ）
pnpm import-curriculum <科目一覧.csv>  # 科目一覧（オフィスアワー含む）を取り込む
pnpm pages:dev  # Pages Functions（/api/ask）込みで手元で動かす（通知先は .dev.vars）
pnpm preview:cloudflare  # 手元から Cloudflare Pages に公開（~/.secrets/kaishi.env が必要）
pnpm secrets    # 質問フォームの通知先を Cloudflare Pages に設定
```

- 構成: Astro（静的サイト）＋ Pages Functions（`functions/`）→ Cloudflare Pages（大学のアカウント、プロジェクト `kaishi-lab`）
- GitHub Actions: `ci.yml`（PR チェック）/ `watch.yml`（毎日 03:00 JST に取り込み）/ `deploy.yml`（main への push で本番、PR ごとにプレビュー）
- デプロイには GitHub の Secrets `CLOUDFLARE_API_TOKEN`（Cloudflare Pages: Edit）と `CLOUDFLARE_ACCOUNT_ID` が必要です
- サイト内リンクは `href()`（src/lib/teachers.ts）を通す
